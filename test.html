Tilt Guard: Black Screen Hide

L'application Tilt Guard vous permet de masquer votre écran en un clin d'œil. Elle propose deux modes : le Mode Manuel et le Mode Auto (utilisant les capteurs de rotation).

Dernière mise à jour : 8 Mars 2026

Résumé Rapide

Données NON collectées

  • Contenu de votre écran
  • Informations personnelles (Nom, Email)
  • Historique de navigation

Données collectées

  • Modèle de l'appareil & OS
  • Rapports de crash (anonymes)
  • ID publicitaire (pour AdMob)

SDK Tiers utilisés

Pour assurer le bon fonctionnement, nous intégrons les services suivants :

  • Firebase Analytics & Crashlytics : Pour corriger les bugs.
  • RevenueCat : Pour gérer vos abonnements ou achats in-app.
  • Google AdMob : Pour diffuser des publicités adaptées.

Collecte et Utilisation

Nous ne collectons, ne partageons et ne conservons aucune donnée personnelle. L'application utilise les capteurs de votre téléphone uniquement localement pour déclencher l'écran noir en Mode Auto.

Conformité RGPD & Protection des enfants

Pour les utilisateurs de l'UE, nous respectons le RGPD via les mécanismes de consentement Google. L'application n'est pas destinée aux enfants de moins de 13 ans.
