Politique Détaillée

Cette politique de confidentialité explique comment Appicsai collecte et utilise les informations. En utilisant cette application, vous acceptez les termes décrits ici.

Collecte de données

Nous ne collectons aucune information personnellement identifiable. Les données collectées sont uniquement destinées à améliorer les performances de l'application via des outils tiers comme Firebase Analytics.

Services Tiers

L'application utilise des SDK tiers pour fonctionner correctement :

  • Firebase Analytics : Pour comprendre comment l'application est utilisée.
  • Google AdMob : Pour afficher des publicités (identifiants publicitaires anonymes).

Protection des mineurs

L'application n'est pas destinée aux enfants de moins de 13 ans. Nous ne collectons sciemment aucune donnée auprès de mineurs.
