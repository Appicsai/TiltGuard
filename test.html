Tilt Guard

L'application Tilt Guard vous permet de masquer votre écran en toute simplicité. Cette application propose deux modes : le Mode Manuel et le Mode Auto. Le Mode Auto utilise les capteurs de rotation de votre téléphone pour masquer rapidement votre écran lorsque votre téléphone dépasse un certain angle. Vous pouvez également utiliser le mode manuel pour afficher ou masquer votre écran.
